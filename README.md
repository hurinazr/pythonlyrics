# ❄️ Sedetik Lebih Snow Lyrics Animation

A terminal-based aesthetic animation that combines falling snowflakes with synchronized lyrics display.  
Inspired by *Sedetik Lebih* by Anuar Zain, this project demonstrates creative use of Python for text-based visual effects.

---

## ✨ Features
- **[Snowflake animation](ca://s?q=Explain_snowflake_animation_logic)** with varied symbols (`⋆ ꙳ • ♡ ‧ ⟡ ₊ 𖹭`)
- **[Lyrics synchronization](ca://s?q=How_are_lyrics_synchronized_in_code)** with precise timing
- **[Unicode-aware rendering](ca://s?q=Unicode_text_rendering_in_Python)** for proper alignment of wide characters
- **[Centered text display](ca://s?q=Centering_text_in_terminal)** for titles and closing messages
- **[Cross-platform support](ca://s?q=Cross_platform_terminal_clear_in_Python)** (Windows & Unix-like systems)

---

## 📂 Project Structure
- `LYRICS` → List of lyric lines with durations
- `FLAKES` → Snowflake symbols
- `render()` → Handles snow movement and lyric placement
- `render_simple_text()` → Displays static centered text (title/closing)
- `main()` → Orchestrates animation flow

---

## 🛠️ Requirements
- Python 3.8+
- Terminal with ANSI escape sequence support
